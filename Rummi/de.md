# Das Spiel
Das Spiel enthält 106 Spielsteine, darunter 2 Joker. Es gibt 4 verschiedene Farben: Schwarz, Rot, Gelb und Grün, jeweils mit den Zahlen 1 bis 13. Alle Spielsteine werden zusammen gemischt. Jeder Spieler erhält 14 zufällige Spielsteine, die auf sein oder ihr Ablagebrett gelegt werden.

## Ziel
Das Ziel ist, als Erster alle Spielsteine von seinem Ablagebrett loszuwerden, indem man aus ihnen Reihen und Gruppen bildet und diese anschließend auf dem Tisch auslegt.
Jede Reihe muss aus mindestens 3 Spielsteinen derselben Farbe mit aufeinanderfolgenden Zahlen bestehen. Eine Reihe mit den Spielsteinen 12-13-1 ist nicht gültig.

Gruppen müssen aus 3 oder 4 Spielsteinen verschiedener Farben mit derselben Zahl bestehen.

# Joker
Ein Joker kann beim Bilden einer Kombination jeden beliebigen Spielstein ersetzen. Der Joker kann durch Spielsteine ersetzt werden, die bereits ausgespielt wurden. Einen ersetzten Joker darf man nicht behalten, um ihn in einem späteren Zug zu verwenden. Joker dürfen beliebig verwendet und umsortiert werden. Die einzige Einschränkung besteht darin, dass jeder Spielstein am Ende Teil einer gültigen Kombination sein muss.

# Spielverlauf
Um Spielsteine auf den Tisch legen zu dürfen, muss jeder Spieler eine erste Kombination mit einer Mindestpunktzahl aus einer oder mehreren Gruppen bilden.

Die erforderliche Mindestpunktzahl hängt von der Spielstufe ab:

- Leicht -> 27
- Normal -> 30
- Schwer -> 33
- Experte -> 36

Diese Punkte müssen ausschließlich aus Spielsteinen auf der eigenen Hand stammen und dürfen nicht aus Spielsteinen bestehen, die bereits auf dem Tisch liegen. Nachdem du deine ersten Punkte ausgelegt hast, darfst du auf dem Tisch anlegen sowie Kombinationen verändern und umsortieren. Du darfst die Spielsteine anderer Spieler nicht verwenden, um die ersten Punkte zu bilden.
Wenn du an keine der Reihen oder Gruppen von dir oder deinen Mitspielern anlegen kannst, musst du einen Spielstein vom Tisch ziehen. Danach musst du bis zu deinem nächsten Zug warten, bevor du spielen darfst.

# Punktwertung
Nachdem ein Gewinner feststeht, müssen die Verlierer die Werte der Spielsteine auf ihren Ablagebrettern addieren. Dies ist ihre Punktzahl für das Spiel. Ein Joker hat einen Strafwert von 50. Die Punktzahl eines Spielers für das Spiel wird von seiner aktuellen Gesamtpunktzahl abgezogen. Anschließend wird die Punktzahl jedes Verlierers für das Spiel zur aktuellen Gesamtpunktzahl des Gewinners addiert. Angenommen, Spieler A gewinnt ein Spiel, Spieler B hat eine Punktzahl von 5, Spieler C eine Punktzahl von 10 und Spieler D eine Punktzahl von 3. Spieler A hat dann eine Gesamtpunktzahl von 18, Spieler B -5, Spieler C -10 und Spieler D -3.
Falls das Spiel ohne Gewinner endet, gewinnt der Spieler mit den wenigsten Spielsteinen auf seinem Ablagebrett. Die Punktwertung erfolgt anschließend auf normale Weise.
